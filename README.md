# Подарочный интерактивный сайт для Маши ✨ 1 Месяц Знакомства

Создан с любовью в честь 1 месяца со дня знакомства через Roblox Blade Ball (05.08.2026 — 05.09.2026).

## 🌟 Ключевые возможности сайта:
1. **Интерактивная мини-игра Blade Ball**:
   - Реальное парирование неонового шара кнопкой **BLOCK** с официальной иконкой щита или клавишей **Пробел**.
   - Коронные фразы: *«Чуйка спасла! 🔥»*, *«Ты тигрица! ⚡»*, *«Идеальный блок! 🛡️»*, *«15k киллов дают о себе знать! 👑»*.
   - Личный рекорд Маши: **15,000+ киллов**.
2. **2-в-1 переключатель режимов (Кнопки в шапке)**:
   - **📸 Фото-режим**: реальные фото из чата (домашняя фирменная пепперони на противне и запечённая, линейка 11 «И» класса, расписание с 3 физиками подряд, Wuthering Waves, кошечка Пушинка).
   - **🎨 Арт-режим**: авторские стилизованные неоновые карточки с иллюстрациями и визуальными эффектами.
3. **Лаборатория Физики & Космоса**:
   - Формулы с тёплым смыслом: Закон тяготения, Эквивалентность массы и энергии, Первая космическая скорость.
   - Интерактивный холст гравитационного притяжения (управление звёздами курсором/пальцем).
4. **Уголок радости**:
   - Интерактивная анимированная кремовая длинношёрстная мини-такса (виляет хвостом, лает, кушает косточки).
   - Любимые лакомства: шоколадное мороженое, Fitness Shock, книги Анны Джейн («Поклонник»), встреча с Региной Тодоренко.
5. **Музыкальный плейлист месяца**:
   - Лоу-фай синтезатор на Web Audio API (работает автономно без внешних mp3).
   - Треки ILLIT, BTS, OG Buda.
6. **Запечатанный сургучный конверт**:
   - Открытие конверта по клику с залпом праздничного конфетти.
   - Искреннее персональное письмо от Миши с интерактивным счетчиком сердечек.

## 🚀 Как запустить локально:
1. Откройте файл `index.html` в любом современном браузере (Chrome, Edge, Safari, Firefox).
2. Либо запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
   и перейдите по адресу: `http://localhost:8000`.

## 🌐 Как опубликовать на Vercel / GitHub Pages:
1. Инициализируйте репозиторий в этой папке:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Masha celebration website"
   ```
2. Создайте приватный (или публичный) репозиторий на GitHub и сделайте push.
3. Перейдите на [vercel.com](https://vercel.com), нажмите **Add New Project**, выберите репозиторий и нажмите **Deploy**. Сайт опубликуется за 10 секунд!
