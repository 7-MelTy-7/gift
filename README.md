# Новогодняя 3D-Книга Сказка для Маши 📖❄️ 2027

Интерактивная рождественская сказка без блочных рамок, созданная специально для Маши Свечниковой по мотивам её увлечений, характера и мечты.

## 🌟 Особенности новой концепции:
1. **Бесшовное повествование (Borderless Storytelling)**:
   - Никаких видимых прямоугольных блоков или шаблонных карточек. Текст сказки, золотые акценты и интерактивные сцены органично парят в зимнем ночном пространстве.
2. **Сюжет по мотивам полного досье**:
   - **Пролог**: Зимняя Москва, вечерние огни города.
   - **Глава I**: Оверсайз-толстовки, проводные наушники поверх капюшона, BTS, ILLIT, OG Buda, «пипяо», «бубочка» и забота о друзьях.
   - **Глава II**: 11 «И» инженерный класс школы «Дмитровский», сложные тепловые задачи, авиарежим на уроках Наталии Александровны и мечта об астрономии и ракетах.
   - **Глава III**: Живые романы Анны Джейн («Поклонник»), домашняя фирменная пепперони с подругой Сашей, шоколадное мороженое и белоснежная Пушинка.
   - **Глава IV**: Blade Ball, способность «Ангел» 🪽, честная игра без макросов и та самая судьбоносная заявка в друзья!
   - **Глава V**: Снежный шар с заветной кремовой длинношёрстной таксой.
   - **Эпилог**: Персональное письмо от Миши и интерактивный бенгальский огонь.
3. **Медленный умиротворяющий снегопад (Three.js WebGL)**:
   - Снежинки плавно и спокойно парят на ветру в трёхмерном пространстве с параллакс-откликом на курсор.
4. **Реалистичный бенгальский огонь (Sparkler)**:
   - Исправлен алгоритм зажигания: огонь зажигается только при точном чирканье по металлическому кончику, запуская сноп золотых искр и праздничное конфетти для загадывания новогоднего желания.

## 🚀 Как посмотреть:
Откройте `index.html` в браузере или запустите локальный сервер:
```bash
python -m http.server 8000
```
