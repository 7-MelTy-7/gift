# Интерактивная 3D-Книга Сказка для Маши 📖❄️ 2027

Настоящая тактильная 3D-книга сказок с физическим перелистыванием страниц, созданная специально для Маши Свечниковой к Новому Году 2027.

## 🌟 Ключевые возможности 3D-Книги:
1. **Реалистичный 3D Flip-Book движок**:
   - Роскошный кожаный переплёт цвета винного бархата с золотым тиснением и металлическими уголками.
   - Физическое перелистывание страниц с 3D-изгибом, объёмом корешка и падающими тенями.
   - Шелест страниц (синтезируется через Web Audio API).
   - Управление: клики по углам, кнопки «Вперёд/Назад», клавиши со стрелками (← / →), свайпы.
2. **Контролируемое появление текста («Золотые чернила»)**:
   - Текст появляется строка за строкой по клику или автоматически.
   - Кнопка «Весь текст» для быстрого чтения всей страницы сразу.
3. **Анимированные новогодние стикеры на КАЖДОЙ странице**:
   - 🧥🎧 Толстовка с наушниками поверх капюшона;
   - ☕🍫 Кружка горячего шоколада с анимированным паром;
   - 🧚✨ Музыкальные феечки ILLIT, BTS и OG Buda;
   - 🪐🔭 Вращающийся Сатурн, телескоп и формулы 11 «И» класса;
   - 🍕🧀 Аппетитный кусочек фирменной пепперони;
   - 🐱🤍 Белоснежная кошечка Пушинка («Ой какая бубочка!»);
   - 🪽💌 Золотые крылья мейна «Ангел» и письмо с заявкой в друзья;
   - 🐾🎄 Очаровательная кремовая длинношёрстная мини-такса в новогоднем колпачке, виляющая хвостиком;
   - 💌✨ Золотая сургучная печать и подпись «Миша».
4. **Интерактивный бенгальский огонь (Финальная страница)**:
   - Чиркайте пальцем или курсором по кончику бенгальского огня, чтобы зажечь праздничный сноп золотых искр и отправить новогоднее желание к звёздам!

## 🚀 Как посмотреть:
Откройте `index.html` в браузере или запустите локальный сервер:
```bash
python -m http.server 8000
```
